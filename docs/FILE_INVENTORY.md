# File Inventory

The repository contains 70 shell scripts, one Python utility, five configuration files, one HTML file, one ZIP, and native binaries. No Go, JavaScript/TypeScript, runtime JSON, Makefile, Dockerfile, systemd unit, cron file, or database is checked in.

- `SETUP`: installers for SSH, Xray, Caddy, OHP, websocket, bridge, and backup tooling.
- `XRAY`: VLESS account operations, listings, online checks, and certificate helper.
- `MENU`: top-level and SSH/VPN menus.
- `BOT`: Telegram-oriented status, config, usage, and online checks.
- `BACKUP`: local, Telegram, Drive, GitHub backup/restore and log cleaning.
- `SSH`: status, restart, information, DNS, RAM, host and utility commands.
- `change-port`: port mutation scripts.
- `OTHERS`: proxy snippets, HTML, rclone config, speedtest, and helpers.

Opaque payloads include `badvpn-udpgw64`, `SETUP/ohp*`, websocket executables, and `SSHWS-SETUP/vpn.zip`.
