# Dependency Audit

The README recommends Debian 12 and mentions Debian 10/11 and Ubuntu 18.04/20.04. Scripts assume root, Bash, systemd, APT, cron, and non-OpenVZ virtualization.

Dependencies include curl, wget, socat, Python 3, sed, nano, toilet, figlet, jq, gawk, bison, sqlite3, git, xz-utils, zip, openssl, netcat, chrony/ntpdate, DNS tools, Caddy/Nginx, OpenSSH, Dropbear, Squid, OpenVPN, stunnel, fail2ban, vnstat, screen, rclone, build tools, OHP, BadVPN, websocket payloads, speedtest, and optional Netflix tooling.

External services include the operator script host, GitHub, Let’s Encrypt/acme.sh, Telegram, public IP services, `ip.guide`, Google Drive/rclone, Cloudflare ranges, and GitHub backup repositories. There is no application database.
